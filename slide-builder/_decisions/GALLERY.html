Simpler-Architecture Gallery

14 pattern reference for the proposed slide-builder ontology — 9 splits + 3 diagram primitives + 2 special objects + 1 fallback path

Splits (9) — pure geometric layouts

The agent picks one split per slide based on what the brief implies. Variants (canvas mode, typography, accent placement) are agent autonomy within the split.

Split 1 Shippable
Full canvas
Single dominant zone — hero claim, statement, quote, divider. Sparse type as the figure. Light or dark canvas.
Split 2 Shippable
50/50 vertical
Two equal vertical zones with parallel content. Symmetric compares (today vs. tomorrow, option A vs. option B).
Split 3 Shippable
Asymmetric vertical (75/25)
Dominant content panel + anchor/chrome panel. Brand-fill panel typically dark, content panel light. Anchor + supporting evidence pattern.
Split 4 Shippable
Top band + body
Brand-fill top band with headline finding, body beneath with parallel evidence cards. Headline-band-plus-cards pattern.
Split 5 Shippable
N-column row (3-9)
Parallel columns — principles, options, phases, journey stages. Anchor type per column (numeral, icon, label) is variant choice.
Split 6 Shippable
Vertical N-row stack
Vertical stack of anchored rows. Each row: anchor (numeral, icon, label) + headline + body. Lists, principles, capabilities.
Split 7 Shippable
Dense grid (2..5 × 2..5)
KPI scorecard, dashboard tiles, dense card grids. Each cell: value + label + delta + status. Color-coded indicators allowed.
Split 8 Shippable
Left rail + body
Narrow chrome rail (section marker, navigation, eyebrow) + main content body. Used for chapter markers and structured sections.
Split 9 Shippable
Horizontal bands
Two full-width horizontal rows. Before/after, evidence/so-what, current-state/future-state. Visual contrast between bands carries the argument.

Special objects (2) — first-class helpers with their own plumbing

Chart absorbs the old Matrix grid via `chart_type="quadrant"` + `quadrants: [name×4]` parameter. Same primitive renders BCG, scatter plots, line charts, waterfall.

Object 1 Shippable
Chart (with quadrant mode)
Axes + items in 2D space + takeaway. Variants: scatter, line, bar, waterfall, donut, quadrant. Quadrant mode = BCG / Magic Quadrant / Eisenhower (labeled corners + plotted items).
Object 2 Shippable
Table
Banded rows with header. Comparison tables, decision matrices, option scoring. Brand-accent on the recommended row.

Diagram primitives (3) — native python-pptx

Empirically validated as renderable cleanly in native PPT. Use rectangles + explicit (x, y) connectors. Avoid curved containers with text inside.

Diagram 1 Shippable
Org chart (hierarchical)
3-level hierarchy with rectangles + orthogonal connectors. Works for org charts, capability trees, hierarchical breakdowns.
Diagram 2 Shippable
Swimlane (cross-functional process)
Horizontal lanes (functions) × steps with hand-off arrows between lanes. RACI-as-flow, cross-functional process, customer journey with handoffs.
Diagram 3 Shippable
Decision tree (branching)
Root question → branches → leaf outcomes. Diagonal connectors with edge labels. Recommended-path highlight via brand-accent fill.

Fallback path (1) — HTML→PNG screenshot

For diagram briefs that don't render cleanly in native python-pptx — anything with curved containers, text inside circles, free-form network topologies. Render in HTML, screenshot to PNG, embed as image.

Fallback example HTML→PNG fallback
Hub-and-spoke / Porter's Five Forces / Fishbone / Ecosystem map
This is what NOT to build natively. Text inside circles wraps badly — python-pptx can't shape-fit text to ovals. For these briefs: SKELETON_REJECTED protocol fires, system either (a) generates an HTML version + screenshots to PNG + embeds as image, or (b) tells the user this slide type needs SmartArt / manual build.
Empirical validation: 5-agent build test (slidelab-intro brief) → 5/5 SHIPPABLE on diagnostic slides 5/6/9 (twin bug + fabrication bug both solved). 5-agent ontology challenge → 5/5 SHIP IT WITH FIXES (fixes incorporated above). 1-agent diagram feasibility test → 3 of 4 SHIPPABLE natively (hub-spoke fails, fallback path). 1-agent gallery render → 11 of 11 SHIPPABLE after one iteration of self-correction. Total: 12 agents across 4 test rounds, 17 PNGs of evidence. Architecture is empirically validated.
