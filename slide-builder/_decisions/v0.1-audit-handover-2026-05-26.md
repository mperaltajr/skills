## Tier 1 — Blockers before any coworker share (~3 hours)

These prevent v0.1 from working as documented for anyone but Mario.

### T1.1 — Delete `QUICKSTART.md`
- **What's wrong:** Redundant with `examples/RUN.md`. QUICKSTART claims a 3-command sequence using `examples/quickstart-template.pptx` — that file doesn't exist. RUN.md is the canonical walkthrough and acknowledges the user provides their own registered template.
- **Where:** `slide-builder/QUICKSTART.md`
- **Fix:**
  1. Delete `slide-builder/QUICKSTART.md`.
  2. Update `slide-builder/README.md` "Where to start" — replace any QUICKSTART link with `examples/RUN.md`.
  3. Update `slide-builder/SKILL.md` first-time section — point at INSTALL → `examples/RUN.md` (no QUICKSTART step in between).
  4. Update `slide-builder/INSTALL.md` end-of-install — point users at `examples/RUN.md`.
- **Effort:** 15 min.

### T1.2 — Document the worker agent install step
- **What's wrong:** `SKILL.md` says the worker agent at `%USERPROFILE%\.claude\agents\slide-builder-worker.md` is mandatory for Stage 2 (parallel agent fanout). `INSTALL.md` never installs it. A coworker installs everything else, runs the build, Stage 2 silently does nothing.
- **Where:** `slide-builder/INSTALL.md`, agent definition source unclear (probably in Mario's personal `.claude/agents/`)
- **Fix:**
  1. Add `INSTALL.md` Step 6 — Worker agent. State the file must exist at `%USERPROFILE%\.claude\agents\slide-builder-worker.md`.
  2. Decide where the source-of-truth agent file lives. Options:
     - Ship inside skill at `slide-builder/agents/slide-builder-worker.md` + install step copies to `%USERPROFILE%\.claude\agents\`.
     - Document a chat-driven "install the agent" command.
  3. Add a `Test-Path` verification command for the install step.
- **Effort:** 30 min plus deciding where the source-of-truth lives.

### T1.3 — Add `clean.py` safety check
- **What's wrong:** `clean.py` accepts any `--out` path and starts deleting. `--deep` deletes only copies of `option_*.py` and `_prompt.md`. Wrong `--out` = data loss with no recovery. Pointing at a drive root would `rglob` the whole drive.
- **Where:** `slide-builder/scripts/clean.py`
- **Fix:**
  1. At the top of `clean.py`'s main, refuse if `out_dir / "_meta.json"` AND `out_dir / "dispatch_plan.md"` BOTH don't exist. Error message: "doesn't look like a Slide Lab output directory."
  2. For `--deep`, require either an interactive `[y/N]` confirmation that prints the file count first, or a `--yes-i-really-want-to-wipe-prompts` flag.
  3. Refuse if `out_dir.resolve()` is a drive root, the user's home directory, or under `SKILL_ROOT`.
- **Effort:** 15 min.

### T1.4 — Delete dead-broken v1 chassis code in `twins/composer.py`
- **What's wrong:** `twins/composer.py:60` imports `twins.selector.load_catalog` and `twins/composer.py:334` imports `twins.overrides_resolver` — neither module exists. Masked because v2 doesn't reach `compose_deck()`, `_role_map_for()`, or `_blank_unmatched_via_role_map()` today. But any future change reaching those paths explodes with `ImportError`.
- **Where:** `slide-builder/twins/composer.py`
- **Fix:** Delete dead branches: `_get_catalog`, `_role_map_for`, `_blank_unmatched_via_role_map`, `compose_deck`, the `_PATTERN_LAYOUT_HINTS` plumbing. v1 chassis-vocabulary remnants the cleanup missed.
- **Effort:** 1 hour.

### T1.5 — Reconcile Hardline #4 brief-fidelity contract
- **What's wrong:** `SKILL.md:274`, `prompt.md:200`, `_decisions/DECISIONS.md:80` all claim brief fidelity is enforced via `slide-builder/tests/gate4/check_brief_fidelity.py`. That file does not exist (was in v1, archived). Today the thresholds (`structural_flag_count == 0`, `PER_SLIDE_MIN = 0.30`, `DECK_AVG_MIN = 0.70`) are prose only — nothing enforces them at build time.
- **Where:** three docs above
- **Fix:** Pick one path:
  - **(a) Port the check** — copy `slide-builder_archived_2026-05-26/tests/gate4/check_brief_fidelity.py` into `slide-builder/tests/gate4/`, wire it into `build_deck.py` Stage 1 (raise on `structural_flag_count > 0`). Updates the architecture so docs become true.
  - **(b) Rewrite the docs** — acknowledge Hardline #4 is prompt-time-only in v0.1; add Hardline #4 enforcement to the v0.2 backlog with the gate4 path as the target.
- **Effort:** 1 hour for (b), 2-3 hours for (a) including wiring + smoke test.

## Tier 2 — Fix before declaring v0.1 production-ready (~3.5 hours)

### T2.6 — Backup `final_deck.pptx` on overwrite
- **What's wrong:** Re-running `compile_picks.py` silently overwrites the final deck. Hand-edits vanish.
- **Where:** `slide-builder/scripts/compile_picks.py:193-235`
- **Fix:** Before `dst_prs.save(final_path)`, if `final_path` exists, rename to `final_deck.<timestamp>.pptx`. Or require `--force` flag.
- **Effort:** 15 min.

### T2.7 — Add import-smoke check to contract test
- **What's wrong:** `_contract.py` greps script text but never `import`s the scripts. The original `build_deck.py:67` NameError (caught by the prior verification audit) would still slip through this contract test.
- **Where:** `slide-builder/scripts/_contract.py`
- **Fix:** Add a 4th check: `importlib.import_module()` on every pipeline script under `try/except`; assert no exception.
- **Effort:** 30 min.

### T2.8 — Fix Hardline #3 adjacency attribution
- **What's wrong:** Three docs claim 3+ consecutive-same-split scan runs in `finalize_deck.py`. Actually runs in `build_gate_preview.py:211` and `build_review.py:125`. Behavior is right; attribution is wrong in `SKILL.md:220`, `prompt.md:133`, and DECISIONS.md.
- **Fix:** Update doc references to point at the right scripts.
- **Effort:** 15 min.

### T2.9 — Regenerate `TROUBLESHOOTING.md` exit-code tables
- **What's wrong:** Tables claim codes that don't exist (8, 9), split codes that are unified in the actual scripts (Stage-1 sanity is single exit 7 but doc splits into 6 + 7).
- **Where:** `slide-builder/TROUBLESHOOTING.md:15-32`
- **Fix:** Re-derive each table from the script's actual `sys.exit()` calls. Cross-reference each script's top-level docstring.
- **Effort:** 30 min.

### T2.10 — Reconcile `convergence-hold-declaration` with Path D
- **What's wrong:** Banner says RESOLVED but body still routes NFL → v1, references non-existent `nfl-scope-boundary.md`, locks `_meta.json` at schema 1 while code runs 2. Direct contradiction with Path D.
- **Where:** `slide-builder/_decisions/convergence-hold-declaration-2026-05-26.md`
- **Fix:** Either fully update body to match Path D (NFL out of scope, no v1 fallback, schema 2) OR mark the entire doc as superseded and move the lock list into `DECISIONS.md`.
- **Effort:** 30 min.

### T2.11 — Defer v1/v2 history out of the main SKILL.md flow
- **What's wrong:** `SKILL.md:140` tells new users to read `_decisions/DECISIONS.md` (503 lines) and `GALLERY.html` before doing v2 work. A fresh user has zero context for v1/v2/chassis/Path D and bounces.
- **Where:** `slide-builder/SKILL.md`
- **Fix:** Move "Why v2 exists", "v1 retirement", "Status" sections to a `HISTORY.md` at skill root or a single appendix at the bottom of SKILL.md. New-user reading order: what it does → first-time → input contract → register-template → build flow.
- **Effort:** 30 min.

### T2.12 — Replace `INSTALL.md` verification command
- **What's wrong:** Verification at line 92-95 imports private symbols (`twins.composer._clear_existing_slides`). Refactor-fragile and doesn't actually test what matters (mmdc, LibreOffice, agent file presence).
- **Where:** `slide-builder/INSTALL.md:92-95`
- **Fix:** Replace with: `build_deck.py --help` exit 0 AND `mmdc --version` AND `soffice --version` AND `Test-Path` on the worker agent file. Print `install OK` only if all four pass.
- **Effort:** 20 min.

### T2.13 — Loud failure in `finalize_deck.stash_raw()`
- **What's wrong:** `stash_raw()` (line 531-541) silently returns on `replace()` failure (Windows file lock from open PowerPoint, AV, anti-virus). `st.pptx_path` left pointing at original; raw archive empty; build proceeds with no error surfaced.
- **Where:** `slide-builder/scripts/finalize_deck.py:531-541`
- **Fix:** Log swap failure to stderr; set `st.error = f"stash_raw failed: {exc}"` so it surfaces in RESULT.md; optionally retry once after 1-second delay.
- **Effort:** 30 min.

## Tier 3 — Deferred to v0.2 (~1 day if batched)

Roughly 30 items across the four audits. Not blocking v0.1 but should be cleaned in the v0.2 cycle.

**Documentation drift (10 items)**
- `prompt.md:319` still says `twins/helpers.py` "shared with v1" — v1 archived, rationale stale
- `INSTALL.md:62` still references the `-simple` suffix as if Phase 8 hasn't landed
- Hardcoded `m.a.peralta` paths in SKILL.md, reference docs, `_decisions/*.py` example scripts
- TROUBLESHOOTING.md hardcodes Mario's OneDrive convention
- Two duplicate "Input contract" sections in SKILL.md
- `examples/RUN.md` Phase 5 ordering inconsistent with SKILL.md build-flow description
- Convergence-hold references `prompt.md § 5` for verb vocab — actually in § 4 step 1.5
- `DECISIONS.md:434` references non-existent `_decisions/stage-a-precommit.md`
- Anti-patterns.md:155 cites archived v1 exemplar path
- README "one sentence" architecture summary is jargon-dense

**Code edge cases (10 items)**
- `parse_picks` doesn't validate letter against `option_letters()` (compile_picks.py:99) — wrong letter produces misleading error
- `discover_options()` parses `slide_NN/option_X.py` with `int()` — malformed dir name crashes (finalize_deck.py:484, build_gate_preview.py:174)
- `_log.py` opens log file without atexit close — handle leak on hard crash
- `validate_warn()` doesn't catch non-validation exceptions — `meta = "string"` causes AttributeError
- Mermaid `_render_mermaid_png` zero-byte check too lax — 50-byte partial PNG passes
- `content_hash` concatenates fields without separator — `"abc" + "def"` collides with `"ab" + "cdef"`
- `detect_installed_fonts()` shells PowerShell on every finalize, no platform guard — 10s timeout on non-Windows
- `_resolve_mermaid_theme()` uses lax `validate_warn` instead of strict `load_meta_json` — misleading errors on schema drift
- `build_deck.py` writes theme file BEFORE validation — stale theme on disk if validation fails
- Per-script `FALLBACK_MERMAID_TOKEN` constants drift risk — should be centralized in `_paths.py`

**Security hardening (5 items)**
- `mermaid-<slug>.json` written into shared skill directory violates "deck artifacts live with project" rule — should land in `out_dir` not `slide-builder/theme/`
- Per-slide agent scripts execute without sandbox — opt-in `--trust-agent-scripts` flag + AST allowlist check would help
- `register_template.py` overwrites existing brand.yml/theme.json with no backup — add `--force` or backup-on-overwrite
- `diagnostic.py` zip overwrites silently on same-second timestamp — add uniqueness check
- `subprocess.check_call` for auto-pip-install of `pypdfium2` in `slide-qc/scripts/render_slides.py:101` — supply-chain hook; should fail with explicit instruction instead

**Onboarding polish (5 items)**
- `TROUBLESHOOTING.md`, `clean.py`, `diagnostic.py` not linked from README, INSTALL, or any user-facing doc — orphan tools
- `register_template.py propose` flow has no concrete walked example with paths
- README opener doesn't say "this runs inside a Claude Code session, not standalone PowerShell"
- `examples/quickstart-brief.md` should be the entry-point example, but onboarding chain doesn't say so explicitly
- `requirements.txt` verification snippet doesn't match INSTALL Step 1 (missing pydantic)

## Verdict & shipping recommendation

**The v0.1 architecture is genuinely sound** — 14-pattern catalog, FALLBACK_MERMAID, SKELETON_REJECTED, brand.yml-canonical, `_meta.json` schema, `_paths.py` registry, variant seeding, Stage-1 sanity check all enforce what they advertise. Contract test passes. No `shell=True`, safe YAML, HTML escaping consistent, SHA-locked templates.

**Tier 1 fixes are mandatory** — without them, a coworker can't run their first build, and `clean.py` is a live data-loss foot-gun.

**Tier 2 fixes get to "actually production-ready"** — the code-correctness gaps that aren't masked by happy-path operation, and the doc drift that creates false architectural claims.

**Tier 3 is v0.2 backlog** — won't break things, but Mario will be embarrassed handing it to a senior reviewer with these items unaddressed.

**Estimated total to v0.2-grade clean:** ~7-10 hours of focused work. ~3 hours of that gets you safe-to-share-with-a-coworker.
