Three skill domains — connected, not stacked.
Strategy work requires all three. Weakness in one cascades to the others — and the deck pays the price.
Think
  • Frame the problem before reaching for the slide
  • Govern the argument with a single thought
  • Apply MECE structure — not just bullet points
  • Test the "so what" before drafting
  • Identify decisions vs context
Argue
  • Build the logic chain before the visuals
  • Pressure-test claims against counterexamples
  • Sharpen the headline until it stands alone
  • Anticipate the senior partner's first question
  • Distinguish evidence from assertion
Build
  • Match the right page type to the argument
  • Keep the action title doing the work
  • Use chart only when chart adds signal
  • Respect the invariant footer zone
  • Render in PowerPoint, not Word
