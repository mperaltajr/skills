① Start Trigger point — an input, request, or event initiates the process and sends it into the evaluation pipeline.
② Evaluate Input Intake and structure available data. Validate completeness before advancing to the decision gate.
③ Decision Gate Core diamond node. Tests whether defined criteria are satisfied. Branches YES or NO based on outcome.
YES → Outcome A Criteria met. Process completes with approval, forwarding, or execution of the primary action.
NO → Review Step Criteria not met. Route to a corrective loop — revise, amend, or escalate before re-entry.
NO → Outcome B Revised submission or formal closure. Captures the alternative terminal state with clear accountability.
