## 2026-05-26 — Remove "Agenda" as a deck type

> "Remove Agenda as a type of deck. I feel like that's a trap that causes slides to pass through without going over content."

**Where this lives today.** Storyline-helper does not currently list "Agenda" as a standalone deck type. The closest match is **Workshop Design** (`storyline-helper/SKILL.md:120-122, 260, 985-1036` + the "Workshop Design Coaching Overlay" section at end of file). Workshop Design uses "Agenda" as one of five slide-type tags (Agenda entry / Context framing / Working exercise / Capture/synthesis / Closing) and **explicitly bypasses the narrative gate** — "the narrative gate (governing thought, so-what, editorial emphasis) does not apply to agenda and session objective pages — they are not arguments."

That bypass is what Mario means by "trap": Workshop Design decks slide through without per-slide content pressure-testing because the gate is structurally disabled for them.

**Two interpretations to pick between when this gets acted on:**

1. **Remove Workshop Design entirely.** Cleanest. Routes the user to either build the agenda manually outside Slide Lab, or use slide-builder template-fill mode with their existing template.
2. **Keep Workshop Design but remove the gate bypass.** Force agenda/session-objective pages through a content check too — even if "governing thought" is the wrong rubric, some per-slide content scrutiny is required before the brief saves.

Mario's framing ("trap that causes slides to pass through") leans toward option 2 — the problem isn't the deck type existing, it's that slides escape coaching. But option 1 is also defensible if Workshop Design is genuinely outside Slide Lab's value-add.

**Confirm with Mario before changing.** This is a deck-type architecture decision; defaults are not enough.
